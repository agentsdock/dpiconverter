THE DETAILS

Know exactly what changes.

01 / FILES

Supported formats

Use one JPEG, PNG, or BMP image from your device. Download in the original format, JPEG, or PNG. TIFF, ICO, HEIC, and PDF are not accepted by this tool.

02 / METADATA

DPI tag only

The pixel width and height do not change. Print width in inches = pixel width ÷ DPI; print height = pixel height ÷ DPI. With original format selected, the image data remains untouched.

03 / PIXELS

Resize pixels

Enter a width and height in pixels. The browser resamples the image to those dimensions and writes the chosen DPI. Print size then equals the new pixel dimensions ÷ DPI.

Good to know

Does changing DPI improve image quality?

No. The DPI tag tells print software how to interpret existing pixels. To change the pixel count, select Resize pixels and enter new dimensions. Enlarging an image does not restore missing detail.

Can I change image DPI without resizing it?

Yes. Select DPI tag only and Original format. This DPI changer edits the DPI metadata while leaving the pixel data as it was.

Can I convert DPI online on my phone?

Yes. Choose one image from your phone, set the target DPI, and download the result. Processing happens in your browser.
